0.0.2 値の範囲の指定と解除：assume，forget

--> /*－－－－－－－－－－－－－－－－－－－－－－－－－－－
たまに，値の場合分けをして計算しなければならない場合がある．
【論理式の例】
　x ＞ y ： assume(x > y)
　x ＜ y ： assume(x < y)
　x ＝ y ： assume(equal(x, y))
　x ≠ y ： assume(notequal(x, y))
　x ≧ y ： assume(x >= y)
　x ≦ y ： assume(x <= y)
－－－－－－－－－－－－－－－－－－－－－－－－－－－－*/;
(%i2) /*【例２】 x>0, y<0, z<0 の場合*/
assume(x > 0); /* x>0 と仮定する*/
assume(y > 0, z < 0); /* y>0 かつ z<0 と仮定する*/
(%o1) [x >0 ]
(%o2) [y >0 , z <0 ]
(%i3) facts(); /*現在の仮定の表示*/
(%o3) [x >0 , y >0 , 0 >z ]

(%o5) [x >0 , y >0 ]

(facts(), forget(%%));

0.0.3 記号の「型の属性」の宣言：declare(型の属性, 記号)

--> /*－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－
Maximaにおける通常の記号は，デフォルトでスカラー変数として扱われる．
ただし，delare(a, constant)と「aは定数」と宣言しなくても，
diff(a*x, x)のような微分演算では a は定数のように扱われる．
(ゆえに，declare(変数, constant) は，あまりニーズがない．)
【型の属性の種類】
　　scalar ：スカラー
　　nonscalar ：スカラーではない
　　constant ：定数
－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－*/;
(%i1) /*－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－
【例１】 特に記号を定数と宣言しなくても，定数のように扱われる例 (微分，積分)
－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－*/
f: a·x^2 + b·x + c;
(f) a ⁢ x 2 + b ⁢ x + c
(%i2) diff(f, x); /*xによる微分*/
(%o2) 2 ⁢ a ⁢ x + b
(%i3) integrate(f, x); /*xによる積分 (Maximaのintegrate関数では積分定数が付きません)*/
(%o3) a ⁢ x 3 3 + b ⁢ x 2 2 + c ⁢ x
